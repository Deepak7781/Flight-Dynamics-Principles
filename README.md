# Flight Dynamics Principles — Assignment Solutions

This repository contains my solutions, derivations, simulations, and computational implementations for assignment problems from the book:

📘 *Flight Dynamics Principles* by Michael V. Cook

The repository focuses on understanding and implementing the mathematical and physical principles of aircraft flight dynamics, stability, and control using analytical methods and numerical simulations.

---

## Topics Covered

The repository includes assignments and simulations related to:

- Aircraft Equations of Motion
- Coordinate Systems and Transformations
- Aerodynamic Forces and Moments
- Static Stability
- Dynamic Stability
- Longitudinal Dynamics
- Lateral-Directional Dynamics
- Aircraft Performance
- State-Space Modeling
- Eigenvalue Analysis
- Control Response
- Numerical Integration Methods
- Flight Simulation
- Guidance and Control Concepts
